# Contributing

Thanks for helping. Please open an issue before large changes.

- Build and test with JDK 21:
  `./gradlew :rubik-model:jvmTest :rubik-vision:testAndroidHostTest :rubik-solver:testAndroidHostTest :composeApp:assembleDebug`
- Clone with `--recurse-submodules` (or run `git submodule update --init`).
- Keep pull requests focused and add tests for vision or model changes.
- Never commit signing keys, service-account keys, `google-services.json`, or photos of people.
- By contributing you agree your work is released under the MIT License.
