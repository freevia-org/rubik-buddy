## Changes implemented

### AppViewModel.kt (new file)
- Created `AppViewModel : ViewModel()` holding all app state as Compose-observable properties
- Replaces all `remember { mutableStateOf(...) }` in MainActivity that were lost on rotation

### MainActivity.kt
- Wired `AppViewModel` via `by viewModels()`
- Added `BackHandler` on `Screen.SCAN` to navigate back to `Screen.HOME`
- Removed unused `scope` variable

### ScanScreen.kt
- Added camera retry: `cameraRetryKey` + `key(cameraRetryKey) { AndroidView(...) }` + "Retry" TextButton in error banner
- Drag normalization: `dragX/Y %= 360f` after ±3600° to prevent float overflow
- Fixed hint Text to `minLines = 2` so camera card doesn't shift when text changes between 1 and 2 lines

- Same drag angle normalization (±3600° → `%= 360f`)
