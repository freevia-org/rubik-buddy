name: Save conversations as they happen
description: User wants all conversations saved progressively to avoid losing them on crash
type: feedback
---

Save conversation progress as it happens — do not wait until the end of a session.

**Why:** Conversations have been lost when something crashed mid-session.

**How to apply:** At the start of each conversation, create or append to a conversation log file in the project (e.g., `conversations/YYYY-MM-DD.md`). Write key decisions, suggestions, and outcomes as they occur during the session.
