# Security policy

## Supported versions

Only the latest release of Rubik Buddy receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Email
**[info@freevia.org](mailto:info@freevia.org)** with a description, steps to reproduce and
the app version. Please give us a reasonable time to fix the problem before disclosing it
publicly.

## Scope notes

The app requests only the camera permission, has no network access and stores no account
data. This repository must never contain signing keys, service-account keys or
`google-services.json`; if you find any, report it the same way.
